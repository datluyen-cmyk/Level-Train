# Reconstructed playable schema v1

Pack `Assets/RotateRings/Resources/Levels/generated_levels.json`: `{schemaVersion:1,levels:[...]}`.
Level: `{id:int,title:string,referenceId:string,parMoves:int,difficulty:float,parts:[...],links:[...],solution:[...]}`.
Part: `{id:int,kind:"ring"|"slider",x:float,y:float,radius:float,width:float,gap:float,angle:float,color:int,collectible:bool,key:int,lockKey:int,bomb:bool,axis:float,length:float}`.
All angular values degrees CCW from +X. Radius is centerline; default width .28*radius. Ring gap is centered at `angle`. `key`, `lockKey` 0 means none. Slider axis is world angle and length is centerline length; release gesture travels >=radius*1.25 along positive axis. All collectible parts count toward win. Noncollectible rings are anchors but may rotate unless lockKey unmet. Static fixtures can be rendered around anchors/sliders.
Link `{source:int,target:int,bearing:float,pinWidth:float}`. Pin attaches to source and extends toward target. `bearing` is initial world angle FROM TARGET towards SOURCE. Render T-stem between source outer rim and target inner hole (front ring over pin). Source rotation is clamped while any outgoing link active. A link is active while both endpoints remain AND target is slider, or target ring gap is not open toward bearing. Open iff `abs(DeltaAngle(target.angle,bearing)) <= target.gap/2 - 9` (pin clearance). Bearing adds source current-angle minus source initial-angle; geometry construction keeps center spacing compatible. Link activity recomputed every gesture; no permanent dependency data hiding gameplay. A ring releases when collectible, unlocked, and NO incident active links; a slider releases only through its axis drag when outgoing links inactive (incoming threading cleared by sliding). Removed key part unlocks lockKey matches. Bomb is optional cosmetic source property in first pack; no generated bomb levels until contact-explosion parity verified.
User input: mouse/touch arc drag rotates using atan2 delta. While blocked, small tactile spring/wobble, visual pin feedback. Free ring still needs pointer gesture before release; cascade may release touched connected free rings after action. Undo snapshots entire angles/removed/keys/moves. Hint gives next legal solution gesture, never automatically wins. Solutions array `{part:int,angle:float,kind:"rotate"|"slide"}` is generated from same release model; runtime replay debug must independently execute and compare.
This is a declared reduced physical-threading adapter; original native continuous collision Core is unavailable. Source layout/mechanic statistics from all 500 originals are learned, but original continuous-motion difficulty isn't certified. Do not display claims of original human parity in UI.

Expected gameplay: bright smooth raised C-rings with short attached T pins, fixed centers and gap alignment, bars that slide through guides, cream playfield, original extracted UI sprites/audio. Natural progression, level picker 1..300, restart, undo, hint, music toggle, home, clear celebration, next level, save progress. Auto bootstrap runtime when Play in SampleScene or dedicated scene. No APK or standalone build.
